# EcomAssist UK landing page

This is a static, responsive one-page website.

## Files
- index.html — page structure and copy
- styles.css — responsive styling
- script.js — mobile menu, smooth navigation and mailto contact form
- assets/ecomassist-logo.png — supplied EcomAssist UK logo

## Important
The three testimonial cards are explicitly marked as sample placeholders. Replace them with real client testimonials before publishing.

The contact form currently uses `mailto:ecomassist.uk@gmail.com`. For a professional production form that works without the visitor having an email app configured, connect it to a form service or your own backend.

## Publishing
Upload the complete folder to your web host, with `index.html` in the public web root (often `public_html`).

Alternatively, publish it through GitHub Pages and point your domain's DNS records to GitHub Pages.
